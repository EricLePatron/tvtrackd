# X / TikTok / Instagram — posts & scripts prêts à publier

Contenus clé-en-main pour les 3 plateformes. Remplace `[LIEN]` par l'URL finale. Pour TikTok/Instagram, les scripts décrivent le visuel + le texte à dire/afficher.

> **Rappels transverses** : sous-titres brûlés obligatoires sur toute vidéo (visionnage son coupé), palette stricte amber `#FF8A3D` / cyan `#4DD9C4` / fond `#0B0E14`, chiffres en IBM Plex Mono. Ne jamais promettre une fonctionnalité non livrée (app mobile, reco, notifications push).

> 2/3 — De notre côté sur tvtrackd, l'import du .zip TV Time est traité immédiatement, pas de file d'attente — parce qu'on est petit, mais aussi parce qu'on l'a construit pour être rapide dès le départ.

> 3/3 — On n'a pas de moteur de reco ni d'app mobile pour l'instant. Mais si vous voulez juste reprendre votre historique sans attendre : [LIEN]

**X3 — Preuve produit / build in public** · visuel : capture de l'écran export

> Le détail qu'on ne voulait pas rater : l'export JSON de vos données est dispo dès votre premier jour sur tvtrackd, pas seulement le jour où on ferme. La fermeture de TV Time nous a rappelé que ça ne devrait jamais être une fonctionnalité de « sortie de secours ». [LIEN]

**X4 — Réponse aux comptes presse tech FR (Numerama / JDG / Frandroid)**

> Merci pour la couverture. Petit ajout utile pour vos lecteurs qui paniquent : l'export des données TV Time se demande directement dans l'app (Réglages > Vie privée) jusqu'au 15/07, même si on ne compte pas rester sur l'app. Le plus important c'est de récupérer le .zip avant la fermeture.
